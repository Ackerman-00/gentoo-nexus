## Run summary

### Root cause of ALL Build Relay failures (runs 32069926492 through 32069935190)

**gpm ↔ ncurses circular dependency.** In a fresh stage3, ncurses is
installed WITHOUT gpm USE. The package.use heredoc writes
`sys-libs/ncurses gpm`, so Portage must rebuild ncurses[gpm], which
depends on gpm, which depends on ncurses → cycle. The cycle persists
even when both gpm and ncurses binaries exist in the rolling release,
because Portage's dep resolver rejects circular deps regardless of
binary/source.

**Verified from live build logs** (run 32069932526, obsidian build):
```
Error: circular dependencies:
(sys-libs/gpm-1.20.7-r6-20:0/0::__unknown__, binary scheduled for merge) depends on
 (sys-libs/ncurses-6.5_p20251220-4:0/6::__unknown__, binary scheduled for merge) (runtime_slot_op)
  (sys-libs/gpm-1.20.7-r6-20:0/0::__unknown__, binary scheduled for merge) (runtime)
```

**Fix applied** (commit `eb5169a`, local only — cannot push):
In both `build.yml` and `build-gentoo-official.yml`:
1. Remove `sys-libs/ncurses gpm` from the package.use heredoc
2. After heredoc, install gpm: `FEATURES="-getbinpkg" emerge --oneshot --buildpkg --usepkg sys-libs/gpm`
   (stage3 ncurses has no gpm USE → no cycle)
3. Then append: `echo 'sys-libs/ncurses gpm' >> /etc/portage/package.use/nexus`
4. Target emerge finds ncurses[gpm] depends on gpm (already installed)

### BLOCKER: Cannot push workflow changes

`opencode-schedule.yml` permissions block (lines 16-21, 31-36):
```yaml
permissions:
  contents: write
  pull-requests: write
  issues: write
  actions: write
  id-token: write
```
**Missing: `workflows: write`**

Without this, the GITHUB_TOKEN from every scheduled run lacks permission
to push any `.github/workflows/*.yml` changes. Every push attempt is
rejected: "refusing to allow a GitHub App to create or update workflow
without `workflows` permission".

**Manual action required:** Add `workflows: write` to BOTH the top-level
AND job-level `permissions:` blocks in `.github/workflows/opencode-schedule.yml`.
Then re-run this schedule to push the fix.
