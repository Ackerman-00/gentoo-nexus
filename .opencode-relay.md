## Run summary

### Root cause of ALL Build Relay failures (runs 32069926492 through 32069935190)

**gpm ↔ ncurses circular dependency.** In a fresh stage3, ncurses is
installed WITHOUT gpm USE. The package.use heredoc writes
`sys-libs/ncurses gpm`, so Portage must rebuild ncurses[gpm], which
depends on gpm, which depends on ncurses → cycle. The cycle persists
even when both gpm and ncurses binaries exist in the rolling release,
because Portage's dep resolver rejects circular deps regardless of
binary/source.

**Verified from live build logs** (run 32069932526, obsidian build):
```
Error: circular dependencies:
(sys-libs/gpm-1.20.7-r6-20:0/0::__unknown__, binary scheduled for merge) depends on
 (sys-libs/ncurses-6.5_p20251220-4:0/6::__unknown__, binary scheduled for merge) (runtime_slot_op)
  (sys-libs/gpm-1.20.7-r6-20:0/0::__unknown__, binary scheduled for merge) (runtime)
```

**Fix applied and pushed** (commit `b467d91`, applied manually by owner — the
agent's GITHUB_TOKEN cannot push workflow files):
In both `build.yml` and `build-gentoo-official.yml`, a self-healing block was
added after the Perl stack check: if the installed ncurses binary lacks gpm
USE, bootstrap in dependency order (ncurses `-gpm` binary → gpm binary →
ncurses `+gpm` source rebuild) and regenerate the binhost index.

### BLOCKER resolved: workflow pushes by agent impossible

`opencode-schedule.yml` permissions block (lines 16-21, 31-36):
```yaml
permissions:
  contents: write
  pull-requests: write
  issues: write
  actions: write
  id-token: write
```
The GITHUB_TOKEN from every scheduled run lacks permission to push any
`.github/workflows/*.yml` changes. Every push attempt is rejected:
"refusing to allow a GitHub App to create or update workflow without
`workflows` permission".

**IMPORTANT: NEVER add `workflows: write` to a workflow's `permissions:`
block.** That key is INVALID for GITHUB_TOKEN and GitHub's validator
rejects the ENTIRE workflow file, killing every run of it.

**Workflow changes must be applied manually by the owner from a local
checkout** (local credentials DO have workflow push permission), exactly as
done for commit `b467d91`.
