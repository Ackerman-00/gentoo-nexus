- dev-libs/nss + nspr source-build on PLAIN 64-bit ~amd64 consumers: nexus ships
  nss/nspr ONLY with `abi_x86_32` (GAMING/steam heredoc), so a non-steam consumer
  that pulls obsidian (which RDEPENDs on nss/nspr) matches neither the official
  stable nss-3.112.5 (older) nor the nexus abi_x86_32 build and compiles the
  tree's nss-3.126.1/nspr-4.40. Steam consumers get the nexus binary. This is
  doctrine-consistent (deviation with no nexus build → source build by design)
  but worth noting for obsidian consumers.
- libdrm slot conflict between nexus build (video_cards amdgpu radeon) and
  official host build (video_cards intel nouveau) when abi_x86_32 is enabled —
  pre-existing, requires separate investigation.
